# Sentinel Fielddesk：参考样本辅助判读台

这是面向 `validation_reference_900_v1/points/interp_sheet_900_v3_assisted.csv` 的浏览器判读工具。它按点位加载 2019–2025 年 Sentinel-2 L2A 年度优选场景，并在中间提供 RGB、近红外假彩色、高清历史参考和 NDVI 四联动视图；四个窗口的中心、缩放、拖动和年份保持同步。左侧队列完整显示当前筛选范围内的点位，四个地图用低透明度小点显示全量位置，当前点以透明十字准星标记；右侧“年度判别”栏上方同步显示当前点的指数时序、辅助偏向和预填类别来源。

## 启动

在 `D:\Desktop\cs` 目录打开终端，运行：

```bash
python -m http.server 5173
```

然后打开：<http://localhost:5173/sentinel_labeling_app/>

Windows 下也可以直接双击 `启动判读台.bat`，它会自动启动服务并打开页面。

不要直接双击 `index.html`，因为浏览器会阻止页面读取同目录之外的 CSV 文件。

## 默认数据

页面启动后自动读取：

```text
validation_reference_900_v1/points/interp_sheet_900_v3_assisted.csv
```

也可以点击右上角“载入 CSV”选择另一份结构相同的判读表。辅助表中的类别码会按 `1 林地、2 灌草地、3 水田、4 旱地、5 建设用地、6 水域、0 不确定` 显示；`src=auto` 的已有类别可复核，`src=manual` 的空白年份需要判读，`src=copy2021` 等待 2021 年结果复制。系统只在浏览器 localStorage 中保存当前文件的修改，不会覆盖原始 CSV；点击“导出判读表”生成新的带日期文件。

## 判读操作

- 年份条切换 2019–2025；每个年份的地类标签独立保存。
- 数字 `1–6`：依次选择林地、水田、旱地、建设用地、灌草地、水域；数字 `7` 或 `U` 选择不确定。
- `← / →`：切换年份。
- `N`：进入下一个点；开启“只看当前年份未判”后会跳过已判点。
- `P`：上一个点。
- `S`：保存当前点位到浏览器缓存。
- “保存并进入下一点”：保存后按当前筛选条件继续判读。

## 影像说明

影像来自公开的 Microsoft Planetary Computer STAC/Data API：

- 数据集合：`sentinel-2-l2a`
- 查询范围：当前点位，优先当年 5–10 月、云量低于 40% 的场景
- 回退策略：若没有结果，放宽到全年、云量低于 75%
- 左上地图：Sentinel-2 `visual` RGB，约 10 m
- 右上地图：同一景 Sentinel-2 的 B08/B04/B03 近红外假彩色，植被通常呈红色
- 左下地图：Esri World Imagery Wayback 历史参考；系统从同年快照中选择与当前 Sentinel-2 代表场景日期最近的版本，并标注“近同期参考”或“年度参考”；若该年份没有可用版本，回退到当前高清底图；高清窗允许继续放大到 Z23，实际源分辨率随位置变化
- 右下地图：同一景 Sentinel-2 的 NDVI，按 `(B08-B04)/(B08+B04)` 计算，色带固定按 0–1 显示，低于 0 的水体、裸地和低值区域按 0 显示
- 四图联动：中心点、缩放级别、拖动范围和当前年份同步
- 工具栏准星按钮或 `M`：隐藏/显示四个窗口中的点位准星
- 工具栏 `•••`：隐藏/显示四个窗口中的全量点位；全量点位不会替代当前点准星
- 时序参数面板：位于右侧“年度判别”栏上方，按当前点和当前年份逐月选取低云量 Sentinel-2 场景，绘制 NDVI、NDWI、LSWI 时序曲线；NDVI 按 `(B08-B04)/(B08+B04)` 计算并限制在 0–1，曲线纵轴按当前数据自动缩放并保留 0 基准线，NDWI 按 `(B03-B08)/(B03+B08)` 辅助识别水域，LSWI 按 `(B08-B11)/(B08+B11)` 辅助判断植被水分；当前代表场景的 NDBI 按 `(B11-B08)/(B11+B08)` 保留在曲线下方作为建设用地参考。曲线结果只作快速偏向提示，不会自动替代人工类别判断

Esri Wayback 的版本日期是 World Imagery 的发布快照日期，不等同于每个位置的实际采集日期；即使标为“近同期参考”，也可能与 Sentinel-2 存在传感器、分辨率和拼接日期差异，适合做同期纹理辅助，不应要求两幅图像素级一致。

判读类别为林地、水田、旱地、建设用地、灌草地、水域和不确定七类。已有辅助类别会直接显示在页面，人工修改后仍按辅助表的数字类别码导出。导出判读表时不再输出 `conf_年份` 置信度字段；原始 CSV 保持不变。
